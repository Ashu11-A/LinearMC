## Changes

- CanvasMC 26.3 #1010 (`a636063e`, 2026-11-05). Three overlay adapters changed to match upstream. `RegionFile.write(ChunkPos, ...)` is now `protected`, so the public long-key bridge is the entry point. `SimpleRegionStorage` no longer writes `dfuType` in its 5-argument constructor. `RegionFileStorage` moved chunk recovery to `RegionFileRecovery` and dropped `isChunkData`. All 140 NMS tests pass on this pin.
- XXH64 now comes from OpenHFT. `LinearXxHash64` is gone; `net.openhft:zero-allocation-hashing:2026.0` (`LongHashFunction.xx()`, seed 0) produces the same bytes as the old code. Folia, Canvas and the Horizon plugin all use the dependency.
- CanvasMC 26.1.2 and 26.2 are archived under `versions/servers/removed/` and are no longer built or tested. Their v1.1.3 jars are still available.
- Horizon is one jar for every host. It is built against the oldest supported bundle (26.1.2) with `api-version: 26.1` and tested against 26.1.2, 26.2 and 26.3 on every push. Paper, Folia, CanvasMC and compatible forks run that jar.
- Fork jar names now end in `+build.<N>`, and these notes write the build as `#N`. For example: `linearmc-canvas-26.3-1.1.4+build.1010.jar`.
