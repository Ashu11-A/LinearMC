## Data safety

- The Folia and CanvasMC forks wrote Linear regions only on save or eviction. Edits in unloaded chunks stayed in memory until the next save, and a crash before then lost them. The background flush that only Horizon had now lives in `linear-core` (`linearmc-flush-heartbeat`) and runs on every leg, so a dirty region is written within `flush-frequency` + 1 s, about 11 s with the default. There are no new config keys, and Anvil worlds are not affected.
- Fresh worlds crashed at boot on the Folia 26.3 fork. Startup conversion created empty nether and end folders before the worlds loaded, and Paper 26.3 treats those as existing world data. Startup conversion now skips dimension folders that do not exist.

## Upgrading

- Forks: replace the jar. Worlds that are already Linear need nothing else.
- Horizon: replace the jar. On an existing `.mca` world, take a backup before the first boot, because it converts to LINEAR by default. Set `format: ANVIL` in `plugins/LinearMC/config.yml` to keep Anvil.
